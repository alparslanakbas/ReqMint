# ReqMint 0.1.0 Preview 1 for macOS

This voluntary early-access build is intended to validate ReqMint on real Intel and Apple silicon Macs while the signed marketplace release is prepared.

## Choose the correct download

- `osx-arm64` — Apple silicon Macs (M1 or newer)
- `osx-x64` — Intel Macs

Both archives target macOS 14 or newer and include the matching SHA-256 checksum file.

## Important trust notice

This preview is ad-hoc signed and **has not been notarized by Apple**. It does not establish the developer's verified identity. macOS may block or warn about the first launch. If you prefer a fully verified installation, do not install this preview; wait for the Developer ID-signed, Apple-notarized release or the planned Mac App Store release.

Download only from the official ReqMint GitHub release or [reqmintapp.github.io](https://reqmintapp.github.io/downloads/). After extracting the archive, move `ReqMint.app` to Applications, then Control-click it and choose **Open**. Do not disable Gatekeeper system-wide.

## Preview limitations

- Automated Release tests, bundle validation, architecture validation, ad-hoc signature verification, and checksum verification passed on GitHub-hosted macOS machines.
- Clean-launch, accessibility, update, and removal checks on physical Intel and Apple silicon Macs are still pending.
- macOS Keychain support is not complete. Do not use real API keys, passwords, production credentials, private customer data, or other sensitive values in this preview.
- Automatic updates are not enabled. Future preview builds must be downloaded explicitly.

Please report ordinary defects through [GitHub Issues](https://github.com/alparslanakbas/ReqMint/issues) without attaching credentials, private URLs, request bodies, response bodies, or customer data. Report potential vulnerabilities through [private vulnerability reporting](https://github.com/alparslanakbas/ReqMint/security/advisories/new).

## What comes next

Qualified macOS feedback and aggregate release download counts will guide architecture priorities, physical-device testing, Apple Developer enrollment, notarization, and Mac App Store timing. ReqMint does not enable product telemetry for this preview.
