# دعم ReqMint

> حالة المحتوى: مسودة عربية تحتاج إلى مراجعة متحدث أصلي قبل النشر العام.

## تعلّم مسار عمل

ابدأ من [دليل البدء](README.md) للتعرف على الطلبات والبيئات وتشغيل المجموعات والعمل مع Git. استخدم مساحة العمل التعليمية المؤقتة لتجربة التطبيق دون إرسال بيانات إلى واجهة API خارجية.

## الإبلاغ عن خطأ قابل للتكرار

افتح [مشكلة GitHub](https://github.com/alparslanakbas/ReqMint/issues/new) وأرفق إصدار ReqMint ونظام التشغيل والسلوك المتوقع والسلوك الفعلي وأقل عدد آمن من الخطوات اللازمة لتكرار المشكلة.

احذف رؤوس التفويض وملفات تعريف الارتباط ومفاتيح API وكلمات المرور والعناوين الخاصة ومحتوى الطلبات والاستجابات وبيانات العملاء وأسرار المستودع قبل إرفاق الصور أو السجلات أو عينات مساحة العمل.

## اقتراح تحسين

اشرح مسار عمل المطور والمشكلة التي واجهتها والنتيجة التي تتوقعها. تساعد الأمثلة العامة التي لا تحتوي على بيانات حساسة في تقييم الاقتراح.

## هل اكتشفت ثغرة محتملة؟

لا تفتح مشكلة عامة. اتبع [سياسة الأمان](SECURITY.md) واستخدم نموذج GitHub الخاص للإبلاغ عن الثغرات.
