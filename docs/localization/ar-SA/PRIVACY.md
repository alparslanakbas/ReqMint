# خصوصية ReqMint

آخر تحديث: 24 أغسطس 2026

> حالة المحتوى: مسودة عربية تحتاج إلى مراجعة قانونية ولغوية قبل النشر العام.

ReqMint أداة تطوير محلية أولاً. لا تتطلب شفرة المعاينة العامة الحالية حساباً، ولا ترفع مساحات العمل إلى خدمة ReqMint، ولا تعرض إعلانات، ولا تفعّل تحليلات استخدام المنتج أو القياس عن بعد للأعطال.

## البيانات المخزنة على الجهاز

يخزن ReqMint إعدادات التطبيق وتقدم الإعداد الأولي وسجل الطلبات وملخصات تشغيل المجموعات ومساحات العمل التي يختارها المستخدم على جهازه. تبقى ملفات مساحة العمل في المجلد الذي يختاره المستخدم ويمكن مراجعتها أو مشاركتها باستخدام Git كأي ملفات عادية. مدة الاحتفاظ بسجل الطلبات محدودة، وتُنقح رؤوس الطلبات الحساسة وقيم الأسرار المهيأة قبل حفظ السجل.

يمكن للمستخدم مسح السجل المحلي من داخل ReqMint، وحذف مساحة العمل عبر نظام التشغيل، وإزالة إعدادات التطبيق عبر عناصر التحكم في بيانات التطبيقات بنظام التشغيل.

## نشاط الشبكة

يرسل ReqMint حركة HTTP فقط عندما يشغّل المستخدم طلباً أو مجموعة. تستخدم العينة التعليمية خدمة مؤقتة على جهاز المستخدم ولا تتطلب واجهة API خارجية.

تتطلب عمليات Git الشبكية إجراءً صريحاً من المستخدم وتستخدم المستودع البعيد الذي أعده المستخدم. لا يقدم ReqMint خدمة مزامنة مستضافة. قد تعالج متاجر أنظمة التشغيل ومزودات استضافة Git بيانات التثبيت أو التحديث أو المستودع أو التشخيص بشكل مستقل وفق شروطها الخاصة.

## بيانات الاعتماد والمحتوى الحساس

قد تحتوي رؤوس التفويض وملفات تعريف الارتباط والرموز وكلمات المرور ومفاتيح API ومحتوى الاستجابات ومتغيرات مساحة العمل على معلومات حساسة. يقلل ReqMint من تخزين الأسرار ويفحص ملفات مساحة العمل التي يديرها قبل عمليات النشر المدعومة، لكن المستخدم يظل مسؤولاً عن الوجهات والمستودعات التي يختارها.

## التغييرات والأسئلة

ستُحدّث التغييرات الجوهرية في الخصوصية هذه الوثيقة وتاريخها قبل الإصدار. يمكن إرسال أسئلة الخصوصية عبر [متعقب مشكلات ReqMint](https://github.com/alparslanakbas/ReqMint/issues) دون تضمين بيانات اعتماد أو محتوى طلبات أو بيانات خاصة. يجب إرسال الثغرات الأمنية بالطريقة الموضحة في [سياسة الأمان](SECURITY.md).
