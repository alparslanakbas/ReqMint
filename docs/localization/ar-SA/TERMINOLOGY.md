# مصطلحات ReqMint العربية ومراجعة الجودة

هذه الوثيقة مرجع للمراجعة وليست دليلاً على اعتماد الترجمة. يجب أن يوافق متحدث عربي أصلي ذو خبرة في أدوات المطورين على المصطلحات والسياق قبل النشر العام.

## المصطلحات الأساسية

| English | العربية المعتمدة في المسودة | ملاحظة الاستخدام |
| --- | --- | --- |
| Workspace | مساحة عمل | مجلد ReqMint المحلي وملفاته |
| Collection | مجموعة | مجموعة طلبات قابلة للتشغيل |
| Request | طلب | طلب HTTP |
| Response | استجابة | استجابة HTTP |
| Environment | بيئة | قيم قابلة للتبديل بين الوجهات |
| Header | رأس | رأس HTTP؛ يُترك اسم الرأس التقني من اليسار إلى اليمين |
| Query parameter | معلمة استعلام | اسم المعلمة وقيمتها من اليسار إلى اليمين |
| Collection Runner | مشغّل المجموعات | واجهة تشغيل مجموعة كاملة |
| Assertion | عملية تحقق | شرط يُقيّم نتيجة الطلب |
| History | السجل | السجل المحلي المحدود |
| Stage | إعداد | إجراء Git؛ يُعرض `Git` من اليسار إلى اليمين |
| Commit | التزام | فعل Git مع إبقاء الأمر أو المعرف التقني من اليسار إلى اليمين |
| Push | دفع | إرسال التزامات Git إلى المستودع البعيد |
| Local-first | محلي أولاً | لا يعني غياب كل نشاط للشبكة |
| Background mode | وضع الخلفية | استمرار التطبيق في منطقة الإعلام بعد الإغلاق المختار |

## قائمة اعتماد المتحدث الأصلي

- راجع جميع مفاتيح `ar.json` البالغ عددها 386 مفتاحاً في سياق التطبيق الحقيقي.
- راجع صياغة `ar-SA.json` وحدود حقول Partner Center.
- تحقق من عدم اقتطاع النص عند أصغر حجم نافذة مدعوم وعند تكبير النص.
- اختبر حركة المؤشر والتحديد والنسخ في عناوين URL والرؤوس وJSON والمسارات ومحتوى Git.
- راجع رسائل الخطأ والنوافذ المنبثقة وأسماء الوصول باستخدام قارئ شاشة عربي.
- قارن محتوى الخصوصية والأمان والدعم العربي بالمصادر الإنجليزية الحالية.
- سجل اسم المراجع وتاريخ المراجعة والإصدار أو الالتزام الذي تمت مراجعته قبل إزالة تحذيرات المسودة.
