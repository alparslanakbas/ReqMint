# سياسة أمان ReqMint

> حالة المحتوى: مسودة عربية تحتاج إلى مراجعة متحدث أصلي قبل النشر العام.

ReqMint حالياً في مرحلة ما قبل الإصدار. تُطبق إصلاحات الأمان على أحدث شفرة في فرع `main`، ولا يوجد إصدار بدعم طويل الأجل حتى الآن.

## الإبلاغ عن ثغرة

استخدم [نموذج الإبلاغ الخاص عن الثغرات في GitHub](https://github.com/alparslanakbas/ReqMint/security/advisories/new) عند توفره. لا تنشر بيانات الاعتماد أو الرموز أو محتوى الطلبات والاستجابات الخاصة أو تفاصيل الاستغلال أو بيانات المستخدمين في مشكلة عامة.

أرفق رقم الإصدار أو الالتزام المتأثر، ونظام التشغيل، وخطوات قابلة للتكرار، والأثر، وأي إجراء مقترح للحد من الخطر. سنؤكد استلام البلاغ في أقرب وقت عملي، وسنحقق فيه قبل الإفصاح العام، وسنذكر اسم المبلغ عند طلبه وعندما يكون ذلك مناسباً.

## النطاق

تشمل البلاغات ذات الأولوية العالية كشف بيانات الاعتماد، والتحليل غير الآمن لمساحات العمل أو المجموعات، وتنفيذ الأوامر أو الشفرة، وتجاوز التحقق من الشهادات، ونشاط الشبكة غير المصرح به، والملفات المؤقتة غير الآمنة، وعمليات Git خارج النطاق الذي أكده المستخدم، وحفظ قيم وعد ReqMint بتنقيحها.

تُدار شهادات توقيع الحزم وحسابات المتاجر وأسرار GitHub Actions وخدمات الأطراف الثالثة خارج مستودع التطبيق. لا ترفق قيمها الحقيقية بأي بلاغ.
